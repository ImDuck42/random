## Section III: CSS Styles to replicate the fandom's material icons

### Rarity Colors
| Rarity       | Border    | Gradient ( top -> bottom )                          |
|:-------------|:----------|:----------------------------------------------------|
| `1 (Green)`  | `#4de6aa` | `rgb(42 128 106 / 50%)` -> `rgb(84 204 128 / 50%)`  |
| `2–3 (Blue)` | `#00f0ff` | `rgb(32 113 196 / 50%)` -> `rgb(6 200 242 / 50%)`   |
| `4 (Purple)` | `#ff99ff` | `rgb(136 37 190 / 50%)` -> `rgb(212 104 237 / 50%)` |

### UI Elements
| Icon                                                                                                                 | Name            | Style infos                                        |
|:---------------------------------------------------------------------------------------------------------------------|:----------------|:---------------------------------------------------|
| <img src="https://static.wikia.nocookie.net/honkaiimpact3_gamepedia_en/images/5/51/StripeCode.png" width="32">       | **Stripe code** | `size: 119×20px wtf` `offset: 4px 2px` `no-repeat` |
| <img src="https://static.wikia.nocookie.net/honkaiimpact3_gamepedia_en/images/7/75/Star_%28Small%29.png" width="32"> | **Rarity icon** | `size: 24×24px` `repeat-x` `width = stars * size`  |


### Example Usage
```html
<div class="MaterialIcon" data-rarity="x">
  <img src="item.png" alt="item">
</div>
```
```css
.MaterialIcon[data-rarity="x"] {
  position: relative;
  border: 2px solid #00f0ff;
  background: linear-gradient(rgb(32 113 196 / 50%), rgb(6 200 242 / 50%));
}

/* Stripe behind the image */
.MaterialIcon::before {
  inset: 0;
  content: "";
  position: absolute;
  background: url("StripeCode.png") no-repeat 4px 2px;
}

/* Stars along the bottom */
.MaterialIcon[data-rarity="x"]::after { /* x being the item rarity */
  content: "";
  position: absolute;
  bottom: 4px; left: 4px;
  background-size: 24px 24px;
  height: 24px; width: calc(24 * x)px; /* 1 star × x stars */
  background: url("RarityIcon.png") repeat-x;
}
```

## Section V: Eqipment levels
### Notes
> **I)** Leveling up a ```x+1*``` weapon that got upgraded from ```x*``` will require a different amount of EXP than native ```x+1*``` weapons for the same levels.

> **II)**   Stigmata and Weapons follow the same upgrade rules, but Stigmata are not available for `1*/2*` or `5*/6*` || Pri-Arm rarity.  
> **II-a)** Part 1 `4*/5*` stigmata will not require Honkai Shards but else the same materials as `4*/5*` weapons.  
> **II-b)** Part 2 `4*/5*` stigmata will also not require Honkai Shards and they need the item noted behind the || which can be a different amount or a different item.

> **III)**   Divine Keys are similar to `4*/5*` Weapons with the difference being that every upgrade increases the max level by `5` less than normal `4*/5*`.  
> **III-a)** Thus for, they have one extra upgrade step but still end up at the same max level, being `50`, after reaching `5*` rarity.

> **IV)**   If a weapon has e.g a rarity of ```1*/4*``` like the proto weapons, it will normally follow the rules of ```1*``` up to ```3*/4*``` with a smooth transition between sections.  
> **IV-a)** You know where you will end when looking at the weapons maximal rarity and looking at the table with that behind the slash ```/```.
